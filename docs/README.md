# Overtex documentation

Overtex turns VS Code into a LaTeX writing environment. It builds with latexmk, shows the PDF beside the editor, jumps between source and PDF with SyncTeX, and helps you write, cite, review and submit papers. You only need a TeX distribution, or Tectonic, or Docker.

## Start here

**New to LaTeX, or to Overtex?** Follow the **[tutorial](tutorial/README.md)**. In eight short lessons it takes you from an empty computer to a paper ready to submit: installing TeX, your first document, structure and math, citations, figures and tables, fixing errors, working with co-authors, and submitting. No LaTeX experience needed.

Already set up and something is wrong? See **[Troubleshooting](troubleshooting.md)**: what to do when a build fails, the preview stays empty or a jump lands in the wrong place.
