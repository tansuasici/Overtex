# Tutorial: your first paper with Overtex

This tutorial takes you from an empty computer to a paper that is ready to submit. You do not need to know LaTeX or git: each lesson explains what you type and why.

Do the lessons in order. Each one builds on the project from the one before and takes 10 to 20 minutes.

| # | Lesson | You will learn |
| --- | --- | --- |
| 1 | [Set up](01-setup.md) | Install VS Code, a TeX distribution and Overtex, and check that they work |
| 2 | [Your first document](02-first-document.md) | What a LaTeX file is made of, how to build it, how to jump between source and PDF |
| 3 | [Structure and math](03-structure-and-math.md) | Sections, lists, equations, labels and cross-references |
| 4 | [Citations](04-citations.md) | `.bib` files, citing a paper from its DOI or arXiv ID, the Papers panel |
| 5 | [Figures and tables](05-figures-and-tables.md) | Adding an image and a table from a spreadsheet, and referring to them |
| 6 | [When something goes wrong](06-fixing-errors.md) | Reading errors, the build log, missing packages, undefined references |
| 7 | [Working with co-authors](07-co-authors.md) | Notes, Track Changes and sharing the project |
| 8 | [Submitting](08-submitting.md) | Checking the paper and exporting it for arXiv |

## What you need

- A computer with macOS, Windows or Linux.
- About 5 GB of free disk space for TeX Live (much less if you use Tectonic).
- An internet connection for the installation and for lesson 4.

## Conventions

- **Bold names** like **Overtex: Build LaTeX Project** are commands. Run a command from the **Command Palette**: press `⇧⌘P` on macOS or `Ctrl+Shift+P` on Windows and Linux, start typing its name, and press Enter.
- Shortcuts are given for macOS first, then Windows and Linux: `⌘⌥B` / `Ctrl+Alt+B`.
- Text in a box like the one below is something to type into a file:

  ```latex
  Hello, \LaTeX!
  ```

When you have finished the tutorial, the [guides](../README.md#guides) describe every feature in detail.
