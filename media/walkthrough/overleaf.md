# Work with Overleaf (optional)

Overtex works on local files and does not need Overleaf. You can skip this step.

To work on an Overleaf project from VS Code, add the separate [Overleaf Connect](https://marketplace.visualstudio.com/items?itemName=tansuasici.overleaf-connect) extension, which uses Overleaf's Git integration. Overleaf Connect syncs the project and waits while a build runs, and Overtex builds and previews it.

Overtex itself never connects to Overleaf.
