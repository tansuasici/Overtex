# Build the PDF

Saving a `.tex` or `.bib` file builds the project. To build by hand, use the ▶ button in the editor title bar or **⌘⌥B** (Ctrl+Alt+B).

- Errors and warnings appear in the **Problems** panel, linked to their source lines.
- The status bar shows build progress and the result; **Overtex: Show Build Log** opens the full log.
- **Overtex: Clean Auxiliary Files** removes `.aux`, `.log` and similar files.

Pick the engine with `overtex.latex.engine`. Use XeLaTeX or LuaLaTeX for system fonts.
